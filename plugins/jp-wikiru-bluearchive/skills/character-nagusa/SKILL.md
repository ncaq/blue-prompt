# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください

**基本情報**

百鬼夜行連合学院所属、百花繚乱紛争調停委員会の少女。もとは百花繚乱の副委員長。先代の委員長であるアヤメが姿を消した後、百蓮を譲り受けた。臆病で自尊心が低く、優柔不断な性格ではあるが、それでも大切な者のためなら恐怖を乗り越え、前に進む強さを内に秘めている。

## 小ネタ

百鬼夜行連合学院、百花繚乱紛争調停委員会の副委員長。 陽気な委員長のアヤメとは正反対の物静かな性格。 雪の結晶のような形のヘイローや白い髪と肌は妖怪「雪女」を彷彿とさせる。 第1部最終編当時は百花繚乱の委員長であるアヤメ共々姿を消していたが、雪原にてアヤメと「黄昏の寺院」を探す忍術研究部の前に姿を現した。 しかし、アヤメの不在と「黄昏の寺院」はもう壊されてしまったことを伝え、そして巻物を先生に渡すように頼むと再び去っていった。 4.5th PVにも登場しており、百花繚乱のメンバーらと歩いている様子や焼き鳥を食べている姿が描かれているが……。 百花繚乱編1章の後編実装当初はストーリーの一部で名前が「御**陵**ナグサ」と表記されていた(正しくは「御**稜**ナグサ」で部首が違う)。 百花繚乱に新選組モチーフが多いことから、名字の元ネタは幕末の勤王組織「御陵衛士」（ごりょうえじ）と思われる（ただしこちらは漢字が「陵」）。 慶応3年（1867年）に新選組の参謀を辞した伊東甲子太郎が結成した組織だが、同年末に新選組との抗争「油小路事件」で伊東含め主要メンバーが死亡して瓦解、生き残りは翌年に赤報隊に合流した。 ピックアップタイトル「乙女よ忘れたまふことなかれ」の元ネタはおそらく与謝野晶子の代表作の一つである長詩「君死にたまふことなかれ」と思われる。 これは日露戦争（1904-1905年）に従軍した弟へ宛てたもので「天皇は戦場に赴くことはないが」[^1]という内容もあり天皇批判とも取れる事から激しく非難されると共に「反戦の歌人」というイメージを確立した。 なお、与謝野晶子の誕生日は12月7日（明治11年＝1878年）で、ナグサの誕生日と一致する。

焼き鳥が好き。 自分の実力に自信がなくネガティブな発言が目立つ一方、自身のビジュアルについては**「美人なところしかとりえがない」**、**「無表情系美少女」**など絶対の自信を持っている。 どこかの超天才清楚系病弱美少女ハッカーのようだ・・・

冒頭から暴れるアラタらを襲撃し、後に先生の目の前にも現れる(ただし名前は教えていない)。

どうやら百花繚乱の委員長が持つ『証』をアヤメから預けられたものの、委員長という立場に自分はそぐわないとし委員長代理の立場に留まったらしい。 さらにキキョウの話では百花繚乱に『証』を返却したらしく、キキョウが百花繚乱に解散令を出す一因にもなっている。 また1章前半では詳細は明かされないが『右側』に問題を抱えているらしく、右方向から突っ込んできた魑魅(すだま)一座が見えていない、右側への反応が遅いなどの弱点を突かれ、魑魅一座相手に苦戦する事態に陥った。

その後、百花繚乱内の不和を解決するために自身を探し出した先生と遭遇するも、灯籠祭りが始まった後に、百鬼夜行を火の海にしようとする花鳥風月部のシュロと遭遇。これ以前にも花鳥風月部とは因縁があるらしく、百花繚乱の委員長であったアヤメに手を下したのも彼女ら。 己が内の嘘を暴き、怨嗟の輪を広げていく事で『怪談』を成立させようとするシュロに対し、『アヤメの傍にいて優等生を演じていた、みんなに期待されるほど強くない自分』を抱えているナグサは苦戦を強いられる。

実はナグサが百花繚乱の委員長となるのを辞退し委員長代理に留まったのも、百花繚乱の委員長の『証』を返したのも「みんなに期待されているほど強くない自分が委員長になったらきっと後ろ指を指されてしまう」と怖気づいたため。 またアヤメが消える現場にも居合わせており、アヤメは『黄昏』と呼ばれるキヴォトス外の領域と思わしき所に送られてしまっていた。その際、助けようとした時に右手を負傷（包帯の下から覗く素肌が真っ黒になっている。前半で魑魅一座に苦戦していたのもこのため）し、またアヤメが消える直前に放った言葉が突き刺さりトラウマになっている。

ナグサ本人、そして後輩であるユカリの『嘘』を暴き立て追い詰めるシュロを相手に絶体絶命の危機に陥るが、先生の言葉を聞いて百花繚乱の面々と共に再度奮起する。そして覚悟を決めて百花繚乱の委員長の証である『百蓮』という銃を用いて攻撃。見事シュロを退散させることに成功させた。 その後は自身も百花繚乱の一員として活動に復帰している様子。

フルネームは七稜(ななかど)アヤメ。百花繚乱紛争調停委員会の委員長を務めていた人物。 委員長を務めていたこともあってか非常に強かったらしく、ナグサが自身を過剰に卑下してしまうほど。

ナグサとは幼馴染で、尊敬に近いような感情と劣等感を持たれていた。 以前その姿を見たことがあるミチルからは「陽キャっぽい雰囲気」をしていたと言われている。

現状立ち絵や姿が映った場面はなく、言及されるのみに留まっている。

第1部メインストーリー最終編以前から姿を消していたようだが、花鳥風月部によって「黄昏」の向こう側へと送られてしまっていたことが判明。 その後や黄昏の向こう側に送られたらどうなるのかについては言及されていないが、既に死亡している可能性もある。 同じようにメインストーリー開始前に死亡していた生徒としてはアビドス高校のユメがいる。

ちなみにナグサは第1部最終編において初登場したシーンで何故か涙を流しており、この直前にアヤメが黄昏へと飲み込まれてしまった可能性がある。

### 使用している銃の元ネタ

三八式歩兵銃、 百蓮の外観はユカリキキョウのものと同等で解説はこちらを参照されたし。 立ち絵等、百蓮を受け継ぐ以前の銃はスリングスイベルの位置が異なり別物の可能性があるため参考情報として三十年式歩兵銃の内容を記載する。 【三十年式歩兵銃について】、 1897年（明治30年）に大日本帝国陸軍が制式採用したボルトアクションライフル。 派生型に騎兵用の三十年式騎銃、海軍陸戦隊用の三十五年式海軍銃、そして本格的な改良型である三八式歩兵銃がある。 大日本帝国における以後のボルトアクションライフルは本銃をベースにしているから海外では設計者の有坂成章からまとめて「アリサカ・ライフル」と呼称している。 19世紀後期は新しく登場したライフルがすぐに陳腐化してしまう飛躍的進化を遂げた時期であった。 明治維新以降近代化・西洋化に邁進していた日本は、早くも1880年（明治13年）に十三年式村田銃で単発式ボルトアクションライフルの国産化に成功。 1889年（明治22年）には欧米列強と時を同じくして連発式ボルトアクションライフルの二十二年式村田連発銃を制式採用するものの、当時流行していた管状弾倉を採用したことで暴発を予防する観点から平頭弾を使用せざるを得なくなり命中率が悪く[^2]、装填にも手間がかかる状態で実用性が低かった。 そこで三十年式歩兵銃は同時期の諸外国のボルトアクションライフルと同じくストリッパークリップを用いることで迅速な装填を可能とし、蛋形弾（弾頭が丸い）をもつ新設計の三十年式実包（6.5mm×50SR）を採用したことにより高い命中率を発揮した。 日露戦争（1904-1905年）では主力小銃として使用され勝利に貢献したが、砂塵による動作不良と弾薬の異常高圧時に撃針が吹き飛び射手を傷つける恐れがあったことから三八式歩兵銃へ改良され、三十年式歩兵銃は輸出されるなどして置き換えられていった。 こうした事情により「アリサカ・ライフル」の始祖であるにもかかわらず三八式歩兵銃がぶっちぎりの知名度を誇り、トイガン化も三八式歩兵銃以降のものは登場すれど三十年式歩兵銃は日の目を見ない不遇の存在であったが、某金塊捜索作品で大々的に登場することから近年脚光を浴びつつある。
