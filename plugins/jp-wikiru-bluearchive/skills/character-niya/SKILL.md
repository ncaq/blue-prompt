『ブルーアーカイブ』の生徒「ニヤ」のゲーム内外の事実を調べるためのスキルです。

# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください
- 小ネタはゲーム内外の事実のまとめです。一方、wiki執筆者による解説や運用考察は著作権方針により含めていません。必要な場合は出典のページを直接参照してください

**基本情報**

百鬼夜行連合学院所属、陰陽部の部長。部外者には生徒会長として知られているが、連合学院の成り立ち上、より複雑な事情に縛られている。そのため、「働かない部長」として認知されている……と言い訳するが、仕事をしたがらない性格は天性のもの。いつも興味本位で事件を起こすように見えるが、その裏には他者に明かさない本音が秘められているようだ。

## 小ネタ

百鬼夜行連合学院、陰陽部の部長。 正式な生徒会が存在しない百鬼夜行において実質的な代表を務める。 表情にはいつも~~胡散臭い~~笑みを浮かべており、糸目だが瞳を見せることはほぼない。 陰陽部ではカホの小言をのらりくらりと躱して彼女を困らせているが、本気で怒ったカホには勝てない様子。

傍迷惑な策略家で、手段を選ばないやり口でしばしば騒動を引き起こす。 本人にはそんな状況を楽しんでいるかのような節もある。 しかしながら、彼女が引き起こす事件は最終的に丸く収まり、むしろ騒動の中でその他の別問題まで同時に解決するような結果に落ち着く。 シャーレの先生からも「全部狙ってやっているの？」と問われるが、本人曰く「偶然、たまたまですよ♪」とのこと。 その真相は彼女のみぞ知る。

犯罪界のマスター「ニヤニヤ教授」を名乗り、魑魅一座・気まぐれ流に対してチセを誘拐する計画を立案した、「不忍ノ心」で起こった事件の黒幕。 しかし、事件を静観し、むしろ「和楽姫」の公演(という名目の忍術研究部と魑魅一座の追いかけっこ)を実況して盛り上げるような立ち回りに徹する。 つまり、彼女は**「自ら事件を引き起こすことで忍術研究部と魑魅一座を和楽姫の引き立て役にした」**のである。しかし、この騒動で活躍したことをきっかけに忍術研究部の知名度は百鬼夜行で一気に広がることとなる。

最終的に和楽姫の公演は盛り上がり、ミチルが気にしていた忍術研究部の知名度問題も解決するという、最初から全てニヤの掌の上の出来事だった。 (魑魅一座の本来の目的は陰陽部に要望を飲ませることであり、逆に陰陽部部長のニヤに利用される形となった)

事件解決後は夜の百鬼夜行にて先生と対話するが、先生には今回の事件はニヤが仕組んだものと看破されており、「シャーレの力をこの目で見たかった」という本心を告白。 ……して黒幕ムーブをするのだが、その後は先生にキツめのお説教を喰らう羽目になった。~~やらかしたことを鑑みればだいぶ甘い処置ではある~~

ピックアップタイトル「あさき夢みし隔てなく」の元ネタは10-11世紀頃に成立したいろは歌の「あさきゆめみし　ゑひもせず（浅き夢みし　酔いもせず）」からで仏教の「寂滅為楽」を元にしているとされる。 また「あさきゆめみし」はそのまま「儚い夢を見た」と読めるが平安時代の平仮名に濁音が使われないため「あさきゆめみじ（＝儚い夢を見たくない）」とする解釈もできる。 この事から「隔てなく儚い夢を見たい」と「隔てのない儚い夢は見たくない」と二通りの解釈をすることができる。 陰陽部の部長という事もあり各種スキル名も陰陽道及び陰陽師に因むものが使用されている。

「悪霊退散」  
陰陽道は古代の天文学や占術の要素もあったが平安時代以降は御霊信仰の高まりから呪術師的要素が強まり「悪霊・悪鬼を退治する」という現代でも一般的に見られる陰陽師のイメージを確立。

「ドーマン・セーマン」  
魔除けの印で格子状の印（ドーマン）と星型の印（セーマン）の事。ドーマンは蘆屋道満、セーマンは安倍晴明という具合に陰陽師が由来とされる。

「急急如律令」  
陰陽師が用いた「悪霊は速やかに退散せよ」という旨の呪文。元々は中国（漢）の公文書で使用された「至急法令に則り執行せよ」という意味の慣用句で日本では「早く願いが叶いますように」と意味合いが変化した。

固有武器の名前はニヤの性格やストーリー上の役割を示唆している。

「口蜜腹剣」  
表面上は親切そうに見えるが、実際は陰険なことを企んでいることを表すことわざ。唐の宰相・李林甫を評した言葉から。

### 使用している銃の元ネタ

十四年式拳銃、 大日本帝国陸軍が1925年（大正14年）に制式採用したオートマチックハンドガン。 原型は南部麒次郎陸軍中将（最終階級）が開発した南部式自動拳銃でこれには8x22mm南部弾を使用する大型（甲）、大型（乙）と7x20mm南部弾を使用する小型の三種類が存在した。 大型には２種類あるが大型（甲）は木製のストックホルスターが使用できるようになっていた。 海外では大型（甲）「グランパ・ナンブ」、大型（乙）を「パパ・ナンブ」、小型を「ベビー・ナンブ」という俗称で呼び分けている。 南部式自動拳銃の詳細な開発年度は不明であるが日露戦争（1904-1905年）の頃には既に販売されていたようである。 更に各国でオートマチックハンドガンの開発が相次いだ時期でもあったので1908年（明治41年）には「四一式自動拳銃」の仮称で大型（乙）がテストされるも陸軍では採用に至らず海軍で「陸式拳銃」として採用されるに留まった。 しかし、第一次世界大戦（1914-1918年）を経てその戦訓から軍備の近代化が課題になると黒色火薬から高威力な無煙火薬へ切り替わっていく端境期にあたる19世紀末期に設計された二十六年式拳銃では流石に他国のハンドガンと見劣りすることから再び大型（乙）から簡素化と耐久性を向上させるように設計を改めたものが十四年式拳銃として採用された。 こうした事情から「南部十四年式拳銃」の俗称で大日本帝国の国軍制式拳銃の代表格として今日でも圧倒的な認知度を誇るが、制式名称としてはあくまで「十四年式拳銃」であり南部麒次郎は直接的に関りが無かった。 十四年式拳銃の設計者は不明であるが銃器関係の特許を取得している吉田智準陸軍少将（最終階級）[^1]説がある。 この「南部十四年式拳銃」という俗称は欧米で「Nanbu Type 14」と表現されていたものが戦後に洋書などで「輸入」され自国のものであるにも関わらず過去を顧みることなく無批判で日本でも使用され定着したものと指摘する意見もある。 使用される8x22mm南部弾は拳銃弾としては珍しいボトルネック型で、先行していた7.65×25mmボーチャード弾や7.63×25マウザー弾などを参考にしたものと考えられるが、この形状の為に威力に対してストレートブローバックなどの簡単な機構を採用することができず後に設計される拳銃に対して大きな足枷になったという指摘をされる事が多い。 威力も.45ACP弾や9×19mmパラベラム弾と比較して低威力と言われるが、それでも.380ACP弾から9×18mmマカロフ弾、9×18mmウルトラ弾並みの威力がある[^2]と評価されており、戦後一時的に使用した警察では「射程・貫通力が過大（であり警察用拳銃として使いにくい）」と評価する資料もある。 この拳銃は機関銃手、憲兵などの小銃で武装する事が難しい下士官や兵卒に対する自衛火器として装備させる「官給品」で後に将校や特殊な兵科向けの小型な九四式拳銃が制式採用されるが第二次世界大戦終結まで平行して生産された。 補足すると当時の陸軍将校らの拳銃は軍服の一種として自身で購入する必要があり南部式小型拳銃などの国産拳銃やブローニングM1910等の.32ACP弾を使用する海外製小型拳銃やリボルバーという具合に全く統一していない状況であったが満州事変～日中戦争勃発で特に海外製拳銃の輸入が途絶えて大幅な拳銃不足に陥り将校にも部隊が保有する官給品の拳銃を貸与する形式に改めているものの、結局は制度を完全に移行させる前に終戦となり国軍は解体された。 また「払い下げ」で購入する事も可能であり将校であっても十四年式拳銃を所持している場合がある。 第二次世界大戦後はGHQ（連合国総司令部）の指導により国軍が解体されると一度は役割を終えるが、一方で海軍に代わって創設された海上保安庁やそれまで使用していたサーベルから拳銃へ転換した警察に対しての必要数が大幅に不足することから連合国軍に接収されたものが返還され再び使用することになった。 この他、特にアジア方面では第二次世界大戦以降に発生した独立戦争や内戦で旧日本軍の残留した兵器も活用されるがその中には当然この十四年式拳銃も含まれていた。 中国では旧日本軍が19世紀頃のフランス軍のホルスターのデザインを引き継いだ大型の蓋付き革製ホルスターに収めていた事から王八盒子（スッポン型ホルスター付き拳銃）やその拳銃自体の形状から鶏腿盒子（鶏もも肉拳銃）と呼んでいたとされる。 長らく製造されたが、その間にいくつか改良や簡素化が施されており円形のトリガーガードを持つものを前期型、大型化した楕円形のものを後期型と類型している。 それ以外にもマガジンが脱落しやすい欠点がありグリップに外付けのスプリングを追加するというかなり無理やりな改良もされた。 第二次世界大戦末期には簡略化も行われ複雑な溝を組み合わせた形状であったコッキングピースもセレーションだけの簡単な形状に変化している。 この他「北支一九式拳銃」なるものが日本が占領していた北京で製造されたとされ、実物が残っている。 これは安全装置を親指付近に移設して分解レバーを備えるという操作性を向上させる改良が加えられているものの、どのような状況で製造させ使用されたのか不鮮明でミステリアスな面がある。 余談だがアメリカのスターム・ルガー社のヒット作である競技用ハンドガン「スタームルガーMk 1」シリーズは南部式自動拳銃及び十四年式拳銃を連想させるスタイルであるが設計者の好みでスタイリングを寄せたと認めており第二次世界大戦後の拳銃史にも一定の影響を与えている。 彼女の銃は1938年にトリガーガードが一般的な円形から軍手を装着した状態でも操作しやすいように楕円形へ大型化された改良型で、十四年式拳銃といえばこの楕円形のトリガーガードを連想する先生も多いだろう。 一方でマガジンボトムは特徴的な半円型ではなく一般的な四角形となっており「スタームルガーMK１」シリーズのような印象を与えている。
