『ブルーアーカイブ』の生徒「ミモリ」のゲーム内外の事実を調べるためのスキルです。

# データの構造

- セクションは基本情報・スキル・固有武器・愛用品・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください
- 小ネタはゲーム内外の事実のまとめです。一方、wiki執筆者による解説や運用考察は著作権方針により含めていません。必要な場合は出典のページを直接参照してください

**基本情報**

百鬼夜行連合学院所属、修行部の優しい副部長。いつも朗らかな笑顔と穏やかな物腰で、皆からの人望が非常に厚い。幼い頃に読んだ少女漫画の影響で「大和撫子」になりたいという夢を抱き、修行部へと入った。幼馴染であり部長でもあるツバキとともに、料理や掃除などの修行に日々邁進している。

**入手方法**

ピックアップ募集「いつか花咲く少女の夢」(2022/02/09～2022/02/16)、復刻ピックアップ募集(2023/04/05～2023/04/12)、復刻ピックアップ募集(2024/03/27～2024/04/11)、通常募集、ショップ（大決戦）

### 使用している銃の元ネタ

杉浦式自動拳銃、 　杉浦銃器製造所（北支工廠説もあり）が製造していた自動拳銃。大日本帝国陸軍将校向けの護身用拳銃として1920年代半ばから製造されていたとされるが詳しい史料が現存しておらず謎が多い存在である。 設計は、当時人気のあったコルトM1903ポケット・ハンマーレスからグリップセーフティを省いたコピーで.32ACP弾と.25ACP弾を使用するモデルが存在するが彼女のものは.32ACP弾の物。 ボトム式マガジンキャッチのボタンが大型である事、百鬼夜行連合学院が日本をモチーフにしている事からおそらくこれが元ネタだと思われる。

　当時の陸軍将校用拳銃は武器ではなく軍服の一種として自前で揃える必要があり手当と自身の懐具合で比較的自由に所持することが出来たが一方で高価でありながら平時では発砲する機会が無いこともあって購入を後回しにされる事が多かったらしく日中戦争で拳銃が大幅に不足する事態に陥り将校であっても官給品を貸与する形式に改めている。 コピー元のコルトM1903ポケット・ハンマーレスも当時の陸軍将校らに人気のあったモデルの一つで小型軽量のハンマー内蔵型であった。 スペイン製のコピーモデルなどが存在し当時は舶来品信仰もあってか当時の将校らはこれら小型軽量であり時として安価に販売される海外製拳銃[^2]を好んで使用していた。

　杉浦式自動拳銃は外交関係の悪化による武器の輸入が見込めない状況下において不足する十四年式拳銃及び九四式拳銃の代わりに調達されたものであると考えられる。 しかし濱田式自動拳銃（.32ACP弾）をベースとする二式拳銃のように8x22mm南部弾化とまではいかなかったようだ。
