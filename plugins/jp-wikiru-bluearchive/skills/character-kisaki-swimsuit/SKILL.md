『ブルーアーカイブ』の生徒「キサキ（水着）」のゲーム内外の事実を調べるためのスキルです。

# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください
- 小ネタはゲーム内外の事実のまとめです。一方、wiki執筆者による解説や運用考察は著作権方針により含めていません。必要な場合は出典のページを直接参照してください

**基本情報**

夏を迎え水着に着替えた山海経高級中学校所属、生徒会「玄龍門」の門主。周囲に助けられ、夏のバカンスへ行くことに。体調も普段より良く、より一層解放感を得ている様子。このような自由時間は珍しいため、色々と「楽しむつもり」。

**入手方法**

ピックアップ募集「淡きこと水のごとし」(2026/06/24～2026/07/08)、通常募集

## 小ネタ

査察（という名目の休暇）のために水着に着替えたキサキ。

キキ状態の水着もあるが、シュンとシュエリンとは違い、衣装差分として存在している。 また、強化した際にランダムでキサキではなくキキとしてのボイスが流れることも。 絆ランク25でも解放されるので、聞き逃した場合は絆ランクを上げておこう。 イベント用のアニメPVではキサキ&シュンverに加え、キキ&シュエリンverも用意されている。

余談だが、EXスキルを発動するたびに上空から水流が発生する。アビドス砂漠でもレッドウィンターのような極寒の雪山でも水流が発生する。 自分を中心に生成したり、味方側から水流を生成する生徒は何人かいるが、上空で生成する例は珍しい。 水着衣装には水を自在に操る能力が備わるのだろうか・・・? また、アイコンが黒の番傘の影響でキサキ1人だけ背景が黒っぽいため目立っており、非常に見つけやすい。 カフェでも番傘を持ち歩いている。 専用家具は非常に大きいため、たくさん家具を配置している先生にとっては~~めちゃくちゃ邪魔~~苦心を強いられる。 1人用にしては異様にデカく、家具の建物部分が完全未使用エリアなので、復刻時に新規生徒と共有になる可能性も高い。
