# データの構造

- セクションは基本情報・スキル・固有武器・愛用品・能力解放・絆ランクボーナス・絆ストーリー・ボイスです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

**基本情報**

アビドス高等学校所属、アビドス対策委員会の気難し屋さんな会計担当。小言が多く、自分の感情を表すことに躊躇しないタイプ。日々口癖のように「こんな学校なんか、潰れちゃえばいいのに！」と言ってしまうが、実は学校の借金を返すために他のみんなに隠れてバイトをしているほど、学校に対する愛情が深い子である。

**入手方法**

青輝石購入 新任教師向けパッケージ、通常募集、アーカイブ募集、任務（Hard）
