『ブルーアーカイブ』のキャラクターが、
どの学校のどの部活・組織に所属しているかを調べるためのスキルです。

キャラクター全体をひと目で見渡す索引でもあります。

# データの引き方

所属の一覧は同じディレクトリのreference.mdにあります。
[学校別キャラクター一覧 - ブルーアーカイブ(ブルアカ)攻略有志Wiki](https://bluearchive.wikiru.jp/?%E5%AD%A6%E6%A0%A1%E5%88%A5)
を機械的に整形したものです。

キャラクター1人が1行なので、
特定のキャラクターの所属を知りたい時はGrepで名前を検索してください。
学校や部活の顔ぶれを知りたい時は、
Grepで`## 学校名`や部活名を検索して該当セクションの周辺だけをReadしてください。

キャラクターは200人足らずで、
テーブルの行以外はほとんど無いファイルなので、
どのキャラクターが居るのかを見渡したい時はファイル全体を読んでも構いません。

# reference.mdの構造

- 見出し(h2)は学校で、その学校のキャラクターが1つのテーブルに並びます
- テーブルは「部活・組織・レアリティ・生徒」の3列です
- 連邦生徒会のように学校の直下にキャラクターが並ぶ所属では、部活・組織のセルが空です
- レアリティは★3・★2・★1と、プレイアブルではないキャラクターを表すNPCです
- 生徒名の直後の半角括弧の「ページ名」は、その名前と食い違うwikiruのページ名です。「カイテンレッド(ページ名: カイテンジャー)」のように、個別ページを引く時は括弧の方の名前を使います
- 「所属不明・所属なし」と「コラボキャラクター」は学校ではありませんが、ページの区分に合わせて学校と同じ見出しに並べています

# 使う時の注意

- 「ユウカ（体操服）」のような衣装違いの別バージョンは、それぞれ別ページなのでこの一覧には出てきません。ただし「シロコ＊テラー」のように所属そのものが変わる別バージョンは、独立したキャラクターとして並びます
- 一覧に無いキャラクターの所属は出典のページで確認してください。名前が似ているだけのキャラクターの所属を混ぜないでください
- 部活の掛け持ちや転属のような、ストーリー上の細かい経緯までは表現されていません。一覧はwikiruが整理した現時点の区分です
