# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイスです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています

**基本情報**

山海経との交流会でチーパオに着替えたレッドウィンター連邦学園、保安委員長のマリナ。パンダの可愛さにメロメロになったり、山海経のおもてなしに感銘を受けるなど、交流会をとても楽しんでいる様子。レッドウィンターとは異なる衣装に戸惑っているが、周囲からは似合っていると好評。

**入手方法**

ピックアップ募集「雪の上に立つ三日天下」(2024/08/21～2024/09/04)、復刻ピックアップ募集(2025/11/05～2025/11/12)、通常募集
