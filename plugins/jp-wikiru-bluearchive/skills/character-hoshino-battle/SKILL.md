# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 表は「列名: 値」の箇条書きに、表の題名はその下の見出しになっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください

## 小ネタ

Vol.1第3章「夢が残した足跡」で登場したホシノの姿。 「覚悟」を決めた為に普段のどこか惚けた「おじさん」の雰囲気が抜け、1年生の頃の激情のままに戦っていた時期を連想させる。 しかし、ホシノを「おじさん」呼びの定着もあり、専ら先生からの呼称は「臨おじ」(臨戦おじさん)。 その半面、（メモロビ含む）雑談や編成等で「おじさん」の自称連呼は3衣装の中で飛び抜けて多い。癖になってんだ、「おじさん」って言うの。 前回のホシノ（水着）と同じく周年限定生徒としての実装となった。（初の周年限定2着持ち。5.5周年までの現在はミカもいる。）、 5周年前後で大量追加された『（臨戦）』生徒の第一号。

アビドスのどこかに眠るとされる「ゲヘナの雷帝の遺産」の列車砲「シェマタ」を巡る策謀に惑わされる中で、「自分達『アビドス生徒会』を『無かった』事にすれば良い（＝自身やユメのかつての行動・想いを否定する）」という発想から「アビドス生徒会副委員長」として後輩たちの「対策委員会」と決別。 それに対し「対策委員会」は正式な手続きによる選挙を行い長らく空白であった「アビドス生徒会」の生徒会長にアヤネを擁立、併存する形で存続していた「アビドス生徒会」と「対策委員会」の生徒会組織を1本化して「アビドス生徒会は正式な生徒会組織であった」と「合法的な手段」で対抗した。 手続き上「アビドス高校の生徒会の書記」へ降格させたホシノをなんとか呼び戻そうと「対策委員会」は奮起するも、目まぐるしく変わる情勢の変化も重なり「対策委員会」の願いを彼女は聞き入れる事が出来なかった。 その背景にはユメに対する贖罪意識を多大に利用した地下生活者の精神干渉が行われていた事も発覚、「雷帝の遺産の破壊」という密命を帯びたヒナの参戦も空しく、事態は地下生活者が望んだ方向に転げ落ちてゆく……

**「……この苦しみも、幸せも、私の人生にとってどれも大切なもの。」**、 **「だから……。苦しんで、後悔して、立ち止まるんじゃなくて……前に進むべきなんだ。」**

第1部最終編で消息を絶っていたシロコ＊テラーまでも巻き込んだ一連の騒動はアビドス生たちとヒナ、そして先生たちの尽力によって地下生活者の野望を挫く事に成功する。 ひと段落ついた後、第2章における黒服とカイザーPMCの騒動で「自分を犠牲にさえしてしまえば良い」という考え方で失敗したにもかかわらず、全く同じ失敗を繰り返した為に対策委員会のメンバーに謝罪している。 後、「対策委員会＝アビドス生徒会」の会長にアヤネから禅譲される形で就任（実際に第1部Vol.1第3章をクリア後はプロフィールの情報も変化する）。ユメ先輩の死を乗り越えて精神的に成長することになった。

また彼女の成長はシロコ＊テラーにも良い影響を与えたようで、彼女も別世界で回収していた対策委員会メンバーの武器をアビドス砂漠に埋葬し、一定の区切りを付けた。 これ以降のシロコ＊テラーのヘイローは一部が修復されたように変化している。

ユメの小ネタなどでも取り上げられているが、対策委員会編はエジプト神話の「オシリスとイシスの伝説」をモチーフにしており、「ホルスの戴冠」すなわち「ホシノの生徒会長就任」という関連性を見出すことができる。

### ファストローディング

攻撃型のノーマルスキルにて記載のある「**ファストローディング**」とは高速でリロードするテクニックのことで、特に一度に給弾出来る弾数に制限のあるチューブマガジン方式のショットガンなどで使われるものを指す。 基本は事前にシェル（銃弾）を取り出しやすい位置に装備し、素早くチューブマガジンに給弾する。ホシノの場合は銃の横部分にファストローディング用に弾をセットしており（通常版の立ち絵が確認しやすい）、攻撃後、ここから素早く弾を給弾しているようだ。銃横部分のファストローディング用の弾が切れた際、つまりノーマルスキル発動中は右手で拳銃を連射しつつ、左手でファストローディング用の弾を再セットしている姿が確認出来る。 ![ファストローディング.jpg](https://bluearchive.wikiru.jp/attach2/E3839BE382B7E3838EEFBC88E887A8E688A6EFBC89_E38395E382A1E382B9E38388E383ADE383BCE38387E382A3E383B3E382B02E6A7067.jpg)、 ちなみに、このノーマルスキルの関係で、一見 攻撃型のほうには通常リロードモーションはないように思える。 …が、通常攻撃で敵を倒しつつ、残弾数０の状態で、ホシノの攻撃範囲に攻撃対象がいない状態だったり、EXスキルや移動スキルでNSの発動を潰したりすれば通常のリロードも見ることはできる。狙って見るのはなかなか難しい。 詳しい挙動は、小ネタ・小ワザ集参照。

### 使用している銃の元ネタ

ホシノが愛用しているショットガン。 プレートキャリアにも様々なポーチを装着しているので弾薬を多大に消費するかつての激しい戦い方を彷彿とさせている。

基本的な事柄はミナ・サヤ・ホシノのページを参照の事。 盾にハンドガンを格納できるギミックを備えていた事やある人物の手に渡った時点でそのハンドガンが紛失した状態であったので個別に保管していたようだ……そして元々の所持者は…… 愛用しているショットガンが弾切れなどを起こした時に使用するバックアップ用であるがハンドガンを使用しながらショットガンに弾薬を装填するといった具合にかなり攻撃的な使い方をする。

ホシノのページを参照。 防弾シールドだが、当然実際には戦車砲なんて食らったら一瞬で溶ける。

基本的な事柄はスズミのページを参照。ムービーパートで使用した他アニメーションパートで「歯で安全ピンを抜く」というエンターテインメントお馴染みの方法を取っている。 しかし実際には手榴弾の安全ピンはそう簡単に抜けない様にかしめられていたり割ピンが使われていたりしていて相当強く引っ張る必要がある[^4]。 その為劇中の様に歯で抜こうとすると逆に歯が抜ける羽目になる。まぁキヴォトス人は人外レベルで頑丈なので気にする必要は無いだろう……
