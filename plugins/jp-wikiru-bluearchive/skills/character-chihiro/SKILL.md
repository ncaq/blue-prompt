『ブルーアーカイブ』の生徒「チヒロ」のゲーム内外の事実を調べるためのスキルです。

# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください
- 小ネタはゲーム内外の事実のまとめです。一方、wiki執筆者による解説や運用考察は著作権方針により含めていません。必要な場合は出典のページを直接参照してください

**基本情報**

ミレニアムサイエンススクール所属、ハッカー集団「ヴェリタス」の副部長。卓越したプログラミング能力を持つハッカーであり、同時にその能力をなるべく乱用しないようにと心がける常識人。いたずらっ子の多いヴェリタスにおける良心的な存在で、常日頃から部員たちに「正しいハッカー倫理」について熱弁しているものの、いざとなれば現場への潜入なども辞さないアクティブなタイプでもある。

**入手方法**

ピックアップ募集「大聖堂からバザールにかけて」(2022/01/30～2022/02/09)、復刻ピックアップ募集(2023/01/11～2023/01/24)、復刻ピックアップ募集(2024/02/14～2024/02/21)、アーカイブ募集、ショップ（総力戦レア）(2024 08/01～)

### 使用している銃の元ネタ

HK416orM27 IAR、 ドイツのH＆K社によって開発されたアサルトライフル。 HK416についてはアカリの項を参照。 チヒロの持っているものは、HK416をベースに「分隊支援火器」としてアメリカ海兵隊で独自に採用されているモデル「**M27 IAR**」ではないかと言われている。

これは、従来において軽機関銃（分隊支援火器）が担っていた制圧射撃という役割を対テロ戦争における市街地戦で「目立つ機関銃手が狙われやすいが弾薬の使用量が減っておりメリットが減じられている」という戦訓により「ならば扱いやすい高精度なアサルトライフルでやらせよう」というコンセプトのIAR（Infantry Automatic Rifle）計画下で開発されたもの。 ほぼ通常のアサルトライフルと見分けがつかないほどに軽量で、事実通常モデルのHK416との構造的な差異は銃身が肉厚の「ヘビーバレル」化しているかどうかの違いがほとんどらしい。 他の兵士と見分けが付き辛い＝優先的に狙われ辛いという利点も見込まれたものでもあったが結果的に機関銃手の機動力も向上する事になった。 当初は野心的なコンセプトであった為にM249軽機関銃「ミニミ」に慣れた射手から不満の声があったが、射撃精度の高さから「正確な1発の射撃は分隊支援火器による3～4発分の射撃に匹敵する」とたちまち高評価を獲得したばかりでなく高精度な点を買われて選抜射手用に「M38 SDMR」を配備した他、海兵隊は全ての歩兵火器をこのM27 IARで統一する方針を表明している。

一方で海兵隊主導の企画であった為に同じく陸戦を主とするアメリカ陸軍ではあまり関心を持っていないようである。これは、海兵隊の分隊員数が15人なのに対し、陸軍は9人と比較的少ないため、より火力の高い機関銃が好まれることもあるようだ。

ちなみに数少ないHK416との区別点としてバヨネットラグ（銃剣の取り付け部）の存在があり、このことからチヒロの銃は「M27 IAR」と判断されるものの、一方で「M27 IARにしてはバレルが短い」という指摘もされている。 ただし、この指摘は特殊部隊向けにHK416A5と同等の11.5インチ銃身に換装した「M27 RWK」も存在している事から独自カスタムの範疇とも言えるだろう。
