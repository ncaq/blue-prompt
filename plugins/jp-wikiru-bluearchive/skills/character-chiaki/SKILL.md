『ブルーアーカイブ』の生徒「チアキ」のゲーム内外の事実を調べるためのスキルです。

# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください
- 小ネタはゲーム内外の事実のまとめです。一方、wiki執筆者による解説や運用考察は著作権方針により含めていません。必要な場合は出典のページを直接参照してください

**「いいネタ、見つかるかも～！」**、 ビジュアルだけは登場していたが、名前が不明だった万魔殿の最後のメンバー。 役割は書記だが、同じ生徒会書記であるノアと比べると、文章ではなく写真での記録をしている。 サツキとは特に仲が良いらしく3rdPVや5thPVでは一緒に行動している姿が見られる。 ノリが良く何でも楽しんでしまう性格。マコトの奇行やイブキの可愛さ、サツキの変な計画も全部『楽しい』『ノリが良い』と笑顔で受け入れる。 そんな彼女でもマコトがサツキの催眠術にかかって『礼儀正しく愛にあふれたマコト』になった時はドン引きしていた。 基本的に明るいムードメーカーのような雰囲気の少女である。 ピックアップ名「元宮チアキは見逃さない」の元ネタは色々と考察されているが、マコトとの整合性を考えるとフリードリヒ・ニーチェの「ツァラトゥストラはこう語った」が有力な候補であると思われる。

### 使用している銃の元ネタ

StG44、 基本的な事柄はジュンコを参照のこと。 彼女の銃はピカティニー・レールを装備しているのが特徴的であるが復刻モデルの中にはこのような近代化改修を行う例もある。 またマガジンの形状はどちらかと言えば5.56x45mm弾用のSTANAGマガジンを意識しているようにも取れるため原型の7.92x33mmクルツ弾以外を使用する復刻モデルの可能性もある。 フラッシュサプレッサーを加工しているようだが、映画で使用されるプロップガンの中には映像の映えを優先して同様の改造をする場合があり“伝説的な銃撃戦”で著名な「HEAT」（1995年）で使用されたFNCのフラッシュハイダーがM16A1のものに交換されていた事が好例。

### 使用しているカメラの元ネタ

チアキが使用しているオレンジ色のカメラは特定の1機種を元ネタとしておらず、複数のカメラの特徴を組み合わせた架空のカメラであると思われる。 元ネタとして考えられるのはPENTAX Option [H90](https://www.ricoh-imaging.co.jp/japan/products/digital/optio-h90/feature.html)または[RZ18](https://www.ricoh-imaging.co.jp/japan/products/optio-rz18/)、Leica [Q2](https://leica-camera.com/ja-JP/photography/cameras/q/q2-black)、Nikon1 [J2](https://www.nikon-image.com/products/mirrorless/lineup/j2/)あたりか。

- コンデジかミラーレスか、 カメラ全体の外形やサイズのコンパクトさを考えるとDSLRではなくコンデジかミラーレスのどちらかであることは間違いないが、チアキのカメラは両方の特徴を備えており断言ができない状態である。 ストロボが本体に内蔵されている点やストラップ(三角環)を取り付ける部分が存在しない点はコンデジらしい特徴であるいっぽう、レンズが完全沈胴式ではなく本体から飛び出ている点やレンズの前玉側が黒色になっている点はミラーレスらしい特徴である。 また、メモロビや家具モーションにおいてファインダーを覗き込むような動作があることや、メモロビとカフェSDではレンズ側面のカラーが異なる(前者はオレンジで後者はシルバー)ため、複数のレンズを交換しながら使っていると考えればミラーレスである可能性は高まる。~~作画ミスの可能性もある~~、 以上を踏まえ、「カメラ本体側はコンデジっぽく、レンズ側はミラーレスっぽくなっている」という結論が妥当であると思われる。 いいネタ、見つかるかも～！
- 左利き用カメラなのか、 通常立ち絵では左手でカメラを持っていることや、光軸が右手側(本体に向かって左側)にオフセットされており左手側の空間が広くなっている(左手でホールドしやすい形になっている)ことから、極めて珍しい左利き用カメラである可能性が噂されていた。 が、実装されたメモロビではしっかりと右手でシャッターを切っているため、その可能性は無くなった。 いずれにせよ現実のデジタルカメラは原則的に右手で操作する設計であることから光軸は本体の中心～左手側にあり、光軸が右手側にオフセットしているカメラはかなりレア、あるいはそもそも存在しないため、元ネタのカメラを断言できない一つの要因となっている。 その目的としては現実に存在するカメラから遠ざけるためか、あるいは忍者ニンペロさんステッカーを目立たせる(右手でカメラを構えても塞がれない左手側の位置にステッカーが貼れるような広いスペースを作る)ために敢えて左右反転させた可能性が考えられるが、推測の域を出ないものである。
