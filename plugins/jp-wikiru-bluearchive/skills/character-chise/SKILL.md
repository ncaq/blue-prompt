# データの構造

- セクションは基本情報・スキル・固有武器・愛用品・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 表は「列名: 値」の箇条書きに、表の題名はその下の見出しになっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください
- 小ネタはゲーム内外の事実のまとめです。一方、wiki執筆者による解説や運用考察は著作権方針により含めていません。必要な場合は出典のページを直接参照してください

### 使用している銃の元ネタ

ダネルMGL（MGL-140）、 南アフリカのミルコー社が開発した、連発式の軍用グレネードランチャー。 40x46mmのグレネード弾を、回転式弾倉により6発まで連続して射撃が可能ないわゆるリボルビング・グレネードランチャーと呼ばれる銃である。 ちなみに当初はミルコー社からダネル社（初期はアームスコー社）に海外輸出を委託していた都合上「ダネルMGL（アームスコーMGL）」と呼ばれることが多い。 現在はアメリカ国内に『ミルコーUSA』が設立されており、アメリカ軍に売り込みが行われている。

当時グレネードランチャーと呼ばれる兵器の多くが単発式であり、それらは一度撃った後は射手が再装填までの間完全に無防備となってしまう欠点があった。 本銃はそれを複数の弾薬を装填できるようにして解決したものであり、連発できるグレネードランチャーの先駆けとして革新的な兵器であった。 （ただしリボルバー拳銃と異なりシリンダーが重いため、装填時にあらかじめ巻いておいたバネの力で回転させる）、 また角度調整可能な光学照準器が弾倉上部に標準装備されており、グレネードランチャーの本懐である「上に角度を付けて放物線でグレネード弾を射出する」際に狙いを付けやすいという利点もあった。

大火力でありながら扱いやすく警察で用いられる非殺傷のガス弾などにも対応した、優秀で汎用性の高いグレネードランチャーであり、本国の南アフリカを初めとしていくつかの国に輸出されて軍や警察などで使用されている。 中でもアメリカ軍ではハンドガードにピカティニーレールの配置やM4に似たスライド式ストックへの変更などを施した改良型「MGL-140」が制式採用されており、チセの持つものはこれが近いと思われる。

[^1]: テキストでは「縁起が良い」の「が」が抜けている。
