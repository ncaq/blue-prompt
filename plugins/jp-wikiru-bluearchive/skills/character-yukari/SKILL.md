『ブルーアーカイブ』の生徒「ユカリ」のゲーム内外の事実を調べるためのスキルです。

# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください
- 小ネタはゲーム内外の事実のまとめです。一方、wiki執筆者による解説や運用考察は著作権方針により含めていません。必要な場合は出典のページを直接参照してください

百鬼夜行連合学院所属、百花繚乱紛争調停委員会の1年生。由緒正しい勘解由小路家の跡継ぎ。家業を継ぐよりも、憧れの百花繚乱に入った少女。百花繚乱であることに誇りを持っており、行動力がある。時には挫けることもあるが、すぐに立ち上がれる芯の強さを持っている。先輩を尊敬しており、その中でも特にナグサを慕っている。

### 使用している銃の元ネタ

三八式歩兵銃

1905年（明治38年）に大日本帝国陸軍が採用した6.5mm×50SR弾を使用するボルトアクション方式ライフルである。南部麒次郎が中心となって前身にあたる1897年（明治30年）に制式採用された三十年式歩兵銃を改良して制作された。 1880年（明治13年）に制式採用された十三年式村田銃から始まる国産ライフルの系譜はこの三八式歩兵銃で完成し以後長らく国軍（旧日本軍）を象徴する制式ライフルとして、あるいは海外において三十年式歩兵銃の設計者である有坂成章からまとめて「アリサカ・ライフル」と区分されているため「アリサカ・ライフル」の代表格として認知されている。 初実戦は第一世界大戦における青島などの中国での対独戦であり[^5]、以降のノモンハン事件、シベリア出兵、日中戦争、太平洋戦争と大日本帝国の消滅まで使用された。 製造期間が1942年（昭和17年）まで長期に及んでいるためその間に弾薬も含めて様々な改良が加えられている。 海外へも輸出ないし供与や鹵獲・接収などによって幅広い国で使用された他、中国でコピー生産した六五歩槍などが存在している。

派生型として騎兵が使用する三八式騎銃及び四四式騎銃、スコープを装着できるようにした九七式狙撃銃がある。 さらに1938年に7.7mmx58口径の九九式普通実包を使用できるように改造され、翌年に採用されたものが後継の九九式小銃である。

彼女の持つ個体は照星にガードが設けられ床尾板がカップ状になった後期型で、着剣装置の代わりにスリングスイベル（背負い紐をかける金具）が追加されている。 ……立ち絵ではそうなのだが、固有武器画像や3Dモデルには反映されていない。

後継の九九式小銃（長小銃）は三八式歩兵銃とよく似ているが、ユカリの固有武器画像を見ると銃床が大きな識別点となる。 九九式は機関部の銃床下部が膨らんで銃床の途中に明瞭なくびれがあるのが特徴だが、ユカリの銃は引き金から銃口側へなだらかにつながりほぼ直線的で、三八式らしい形状になっている。 また九九式は上帯（銃床先端の金具）から下帯（その後ろの金具）にかけてがほぼ直線的だが、ユカリの銃はテーパがかかっておりここも三八式に似る。 ただし上帯、下帯の形状は九九式のもので、レンゲ・キキョウの固有武器画像ではレシーバーも九九式の形状[^6]である。 従って「百花繚乱制式ライフル」は「三八式歩兵銃様銃床の九九式小銃」か「九九式小銃様部品の三八式歩兵銃」になってしまうのだが、ワカモページとの差別化も兼ねてとりあえずは三八式歩兵銃とした。

ちなみに九九式**短**小銃のほうは銃身の前側上部が木被（ハンドガード）で覆われていることで容易に識別可能。

余談となるが彼女の射撃モーションは他三名と異なり、フォアエンドを握らずに肘に銃を乗せている。 これは全くのフィクションという訳では無く立射で銃を安定させる時の構え方の一つに似た物があり、本来なら内肘に銃を乗せた状態で左手で右手首を掴んで安定させる手法。 明確な名称が定まっていない方法ではあるが、抱き抱える様な見た目からか米海兵隊では「クレイドル(揺り籠)」の名でスナイパー部隊向けに教えられている。 本ゲームでは三八式歩兵銃がスナイパーライフル扱いな事と合わせて決して無根拠という訳では無さそうだ。最も他モーションやモデリングの都合でこうなっただけだと思われるが…
