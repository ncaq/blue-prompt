# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイスです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています

**基本情報**

山海経との交流会でチーパオに着替えたレッドウィンター連邦学園、秘書室長のトモエ。レッドウィンターとは異なる環境に戸惑いながらも交流会を楽しんでいる様子。新しい衣装も、とても興味深そうに袖を通している。今回の交流会において、彼女の巧みな話術と洞察力は健在のようだ。

**入手方法**

ピックアップ募集「雪の下に咲く二十一日」(2024/08/21～2024/09/04)、復刻ピックアップ募集(2025/11/05～2025/11/12)、通常募集
