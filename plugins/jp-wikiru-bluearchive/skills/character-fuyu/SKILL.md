# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイスです
- 縦に結合されたセルは各行に同じ内容が複製され、横に結合されたセルの残りは空になっています
- 別バージョン(衣装違い)の生徒は別のページなので、このデータには含まれません

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください

**基本情報**

ワイルドハント芸術学院所属、非公認サークル特殊交易部の営業および技術担当。依頼を受けたり依頼人との直接交渉など、特殊交易部の窓口としての役割を果たしている。常に自信に満ち溢れて余裕そうだが……想定外の状況に直面すると、ショックを受けて弱気になることも。

**入手方法**

ピックアップ募集「Collect, Convey, Conclude★★★」(2025/09/24～2025/10/08)、通常募集
