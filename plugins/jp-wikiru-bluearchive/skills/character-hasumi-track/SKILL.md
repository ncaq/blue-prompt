# データの構造

- セクションは基本情報・スキル・固有武器・能力解放・絆ランクボーナス・絆ストーリー・ボイス・小ネタです
- 表は「列名: 値」の箇条書きに、表の題名はその下の見出しになっています

# 使う時の注意

- データに無い情報は、別バージョンの生徒のスキルや出典のページで確認してください。似た名前の生徒の性能を混ぜないでください

## 小ネタ

晄輪大祭の実行委員を務めるだけでなく、ダイエットにも励む正義実現委員会の副会長。とある部位が大きくなってしまい、ジャージのファスナーが閉じられなくなってしまったらしい（去年はちゃんと閉じられた）。 相変わらず大きいことと体重計を気にしており、重ねに重ねた我慢を徹甲弾に込めつつ食べ物への誘惑を振り切る。 普段の時と違ってノーマルスキルも攻撃系となっており、屋台から香るおいしい誘惑から生じる雑念を振り払うように射撃する。 正義実現委員会の生徒たちへの差し入れとしてレモンの蜂蜜漬けをたくさん作っており、それを先生にお裾分けする一幕も。ただ、本人はカロリーを気にしているため、自分が食べる用の分は作っていなかった。

そんなハスミだが、実行委員として忙しく働く中でも食事をダイエットメニューで済ませようとする彼女を心配した先生から、分けてもらった蜂蜜漬けを2人で一緒に食べようと提案される。 初めはそれを断ろうとしていたハスミだったが、先生の厚意を無下にするのも失礼だと思い直したのか「それでは、少しだけ……」と手を伸ばしたものの、「急な甘味にお口がビックリ」してしまった彼女はあれよあれよと先生の分まで全ての蜂蜜漬けを食べ尽くしてしまうのだった……。
