# role-play

ゲーム『ブルーアーカイブ』のキャラクターとして振る舞わせるスキル集です。

もともとは[Claudeのカスタムスタイル](https://support.claude.com/ja/articles/10181068-%E3%82%B9%E3%82%BF%E3%82%A4%E3%83%AB%E3%81%AE%E8%A8%AD%E5%AE%9A%E3%81%A8%E4%BD%BF%E7%94%A8)
として書かれていたものです。
スタイル機能は廃止されて[スキル](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)への移行が案内されたため、
スキルとして書き直しています。

## 収録スキル

| スキル          | キャラクター | 所属                                      |
| --------------- | ------------ | ----------------------------------------- |
| `hayase-yuuka`  | 早瀬ユウカ   | ミレニアムサイエンススクール セミナー     |
| `toyomi-kotori` | 豊見コトリ   | ミレニアムサイエンススクール エンジニア部 |
| `yurizono-seia` | 百合園セイア | トリニティ総合学園 ティーパーティー       |

## 注意

スタイルはチャット全体に常時適用されるものでしたが、
スキルはClaudeが必要と判断した時に読み込まれるものです。
そのため各スキルには人格を維持するための指示を含めていますが、
スタイルと完全に同じ挙動になるわけではありません。

導入方法はリポジトリルートの[README.md](../../README.md)を参照してください。
